# 发布第一篇(草稿)

公众号没有"免登录代发"的接口,所以这一步需要你在后台点几下。材料都已备好。

## 字段

- **标题**:`pstack 拆解 01｜AI 代码为什么总是越写越多`
- **作者**:填你的名字或公众号名
- **摘要**:
  ```
  默认能删就删,加之前先减,用读者的负担而不是行数衡量"少"。
  ```
- **封面**:`wechat/covers/01.png`(900x383,已按公众号比例做好)

## 正文

正文的粘贴版在 `wechat/out/01-principles-restraint.html`(样式已内联,粘进去不掉格式)。

## 步骤(约 2 分钟)

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com),进入「图文消息」→「写新图文」。
2. 填标题、作者、摘要。
3. 用浏览器打开 `wechat/out/01-principles-restraint.html`,在正文区域**全选(⌘A)复制**,粘进公众号正文编辑器。
4. 上传封面 `wechat/covers/01.png`。
5. 点「保存为草稿」。**不要点群发。**

## 或者:让我用 API 代做

如果你希望以后由脚本直接建草稿,需要:

1. 在公众号后台「设置与开发 → 基本配置」拿到 **AppID** 和 **AppSecret**。
2. 把公网 IP `212.87.192.43` 加进「IP 白名单」。
3. 确认你的账号有**草稿箱接口**权限(个人订阅号通常需要认证才有)。

满足后我可以用 `draft/add` 直接建草稿(含封面与正文图片上传)。把 AppID/AppSecret 发我即可。
